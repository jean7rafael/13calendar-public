# Security policy

## Supported version

Security fixes are applied to the current production version published at
<https://13calendar.pages.dev/>.

## Reporting a vulnerability

Please report a suspected vulnerability privately to
`jean7rafael@icloud.com`. Do not include API keys, passwords, personal data or
working exploits in a public GitHub issue.

The project will acknowledge a report as soon as practical, investigate its
impact and publish a corrected release when needed.
